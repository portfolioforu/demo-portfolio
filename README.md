# Demo Portfolio — React

Portfolio de démonstration en React + TypeScript, construit comme preuve de
concept technique pour [Portfolio For U](https://portfolio-for-u.fr).

Le contenu (profil, expériences, projets) est **entièrement fictif** — il
sert uniquement à illustrer le rendu visuel et les animations.

## Stack

- [Vite](https://vite.dev) + React + TypeScript
- [Tailwind CSS v4](https://tailwindcss.com)
- [Framer Motion](https://motion.dev) pour les animations au scroll
- [Lucide](https://lucide.dev) pour les icônes

## Lancer le projet en local

```bash
npm install
npm run dev
```

## Build de production

```bash
npm run build
npm run preview
```
